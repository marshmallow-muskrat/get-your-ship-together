# Cosmic Cleanup! audio

The ambient score in this directory is original, project-owned, and deterministically
generated by `node scripts/generateAudioAssets.mjs`. It contains no third-party
recordings and no files from `assets/space-packs/`.

The browser plays one pre-rendered PCM master at a restrained level. Gameplay, spell,
weapon, pickup, hit, boss, and UI sound effects are intentionally disabled; the current
mix is music-only. The generator is retained as the editable source and provenance
record.
