# Cosmic Cleanup! audio

The ambient score in this directory is original, project-owned, and deterministically
generated by `node scripts/generateAudioAssets.mjs`. It contains no third-party
recordings and no files from `assets/space-packs/`.

The generator renders a 128-second uncompressed master, encodes the two shipped files
from it, and deletes the master — it is an intermediate, not an asset. Regenerating
requires `ffmpeg` with `libopus`.

| File | Size | For |
| --- | ---: | --- |
| `command-deck.opus` | 1.6 MB | Opus at 96 kbps — everything except older Safari |
| `command-deck.m4a` | 2.0 MB | AAC at 128 kbps — Safari fallback |

`AudioBus` probes `canPlayType` and downloads exactly one. The score previously shipped
as a 22.6 MB WAV, which was 57% of everything a first-time visitor downloaded.

Both formats are lossy and pad the tail, so the runtime pins the loop to the authored
128 seconds rather than to the decoded buffer length. `DURATION` in the generator and
`LOOP_SECONDS` in `src/game/audio/AudioBus.ts` must stay in step.
